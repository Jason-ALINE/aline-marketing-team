# ALINE Manufacturing — Company Brief

**Read this before doing any work.** This is the shared source of truth for the
whole marketing team. If something here conflicts with what you're about to
assume, this file wins. If you're relying on a fact that isn't in here, flag it
as unverified rather than stating it with confidence.

## Company
ALINE Manufacturing (Johnson City, Texas) makes shaft alignment tools built
around the **reverse-indicator alignment method**.

## Positioning
ALINE's edge is grounded in what laser alignment tools *don't* fully cover:
- Pipe strain
- Soft foot
- Runout
- Bearing clearance

Reference standards: **API 686** and **ANSI S2.75**. These aren't just
credibility markers — they're often the actual technical hook in content
(e.g., "compliant with API 686" matters more to this audience than generic
quality claims).

**Complementary-use angle (confirmed by Jason, 2026-08-01):** ALINE's tools
were originally designed for reverse-indicator alignment, but have become
popular specifically for checking/monitoring pipe strain. Some millwrights
and technicians use an ALINE tool *alongside* a laser alignment tool rather
than instead of one — laser handles the alignment, ALINE checks pipe strain
in the same job. This is a complementary-tool pitch, not just a
competitive-alternative one, and it changes the ask for prospects who
already own a laser tool: not "replace what you have," but "add pipe-strain
capability to what you already have."

## Buyers — get this right, it's been gotten wrong before
The real buyers and decision-influencers are:

## Verified product specs
- **Tool accuracy: 0.001".** Confirmed by Jason, 2026-08-10. This is the accuracy of every
  ALINE toolset, and it's a direct function of the Starrett 196B1 dial indicator each set
  ships with (.001" resolution) — not a separate ALINE-engineered spec.
- **Don't confuse this with the .0005"/inch-of-coupling-span alignment tolerance
  guideline** (a separate, legacy field rule-of-thumb for general-purpose equipment
  ≤3600 RPM, sourced from the pre-migration `tolerances.htm` page). One is what the tool
  itself can resolve; the other is a target alignment spec crews work toward. Content
  should keep these distinct rather than treating them as the same number.

## Marketing-facing accuracy claims — which number to use
When content makes an ALINE-tool-accuracy claim (product copy, image callouts, CTAs),
use **only** the Starrett 196B1's 0.001" accuracy spec. Confirmed by Jason, 2026-08-10:
"That is the only indicator and accuracy we can supply at this time." Do not substitute
the runout-tolerance rule of thumb (0.002" general / 0.001" for machines above 3,600
RPM — accurate as a cited industry guideline, e.g. in educational blog body copy, but
not an ALINE product claim) or the separate 0.0005"/inch-of-coupling-span alignment
tolerance guideline. All three numbers are real and can appear in educational content,
but only the 0.001" Starrett figure should ever be used when the content is making a
claim about what ALINE's own tools can do.
