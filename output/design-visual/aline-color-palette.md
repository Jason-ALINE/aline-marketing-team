# ALINE Brand Color Palette

Provided by Jason, 2026-08-03. Use this as the source of truth for any design work —
sales sheet layouts, web graphics, SVG diagrams — and feed it into `/design-sync`
before the first `/design` call per the project's Design workflow.

| Name | Hex | Use |
|---|---|---|
| `--navy-deep` | `#0a1a29` | Page background |
| `--navy` | `#10243a` | Secondary background |
| `--navy-card` | `#152b44` | Card/box backgrounds |
| `--steel` | `#7e8da0` | Muted/secondary text, breadcrumbs |
| `--steel-light` | `#c2cdd8` | Body copy on dark background |
| `--paper` | `#edf0f2` | Base text color |
| `--red` | `#bd322c` | Border/darker red accent |
| `--red-bright` | `#dd4b41` | Bright red accent (badges, bullets, highlights) |
| (unnamed) | `#4f8fdb` | Blue accent (used sparingly — links/diagram highlights) |
| (unnamed) | `#fff` | Pure white (headings) |
| (unnamed) | `#152b44` | Reused as card background, soft-foot-check context only |

Dark, navy-forward palette with red as the primary accent and a sparingly-used blue
for links/highlights. Headings run pure white; body copy on dark backgrounds uses
`--steel-light`, not `--paper`, which appears reserved as the general base text color.
