# Design Brief — "Shaft Runout, Deflection, and Whip" Hero Image

**For:** Claude Design (`/design-sync` already run for this project — run `/design <this brief>` directly)
**Replaces:** earlier SVG line-diagram approach, and an earlier draft of this brief built
around the Soft Foot numbered-steps infographic. Both superseded — see revision note below.

## 1. Goal
Give the "Shaft Runout, Deflection, and Whip" post — the site's single best-performing
post (701 views vs. next-best at 98) — a hero image, since it currently has none. This
is a marketing/web graphic, not an engineering schematic, so it belongs with Claude
Design rather than as raw SVG.

**Reference targets (confirmed by Jason):** "Pipe Strain"
(alinemfg.com/post/pipe-strain-what-it-is-why-it-matters-and-how-to-fix-it) and "Why
Pump and Motor Alignment Matters"
(alinemfg.com/post/why-pump-and-motor-alignment-matters-more-than-you-think). Both are
a single, clean, realistic industrial photo — not an infographic. Pipe Strain is an
atmospheric plant/piping shot at night; Why Pump and Motor Alignment Matters is a
well-lit close-up of a pump-motor coupling with visible gauges, pipework, and
real-looking branded equipment in frame. **Match this simpler pattern**, specifically
the framing/lighting/realism of the "Why Pump and Motor Alignment Matters" shot, since
its subject (a coupling close-up) is the closer analog.

*(Note: the Soft Foot post's numbered-steps infographic — the original reference for
this brief — was made with an external AI tool per Jason, and is not the house style
to replicate. Disregard it as a target.)*

## 2. Layout
One photorealistic hero image. No numbered steps, no callout box, no headline banner,
no multi-shot grid.

- Single close-up shot: a dial indicator mounted on a magnetic base, positioned
  against a shaft/coupling hub, in a realistic industrial plant setting — pump/motor
  equipment, gauges, pipework in frame or softly out of focus, similar depth and
  lighting treatment to the "Why Pump and Motor Alignment Matters" reference.
- **No text overlay by default.** If a text element turns out to be necessary, keep it
  minimal and see the one allowable figure noted under Content below — otherwise the
  image should stand alone as a photo, the same way both reference posts do.

## 3. Content
No headline, no step copy, no callout copy — this is a photo-only hero image, not an
infographic, so there's no copy to source from Content for this piece.

**On the one number that's allowed, if any text appears at all:** the only figure that
may ever appear on this image is the **Starrett 196B1's 0.001" accuracy spec** — this
is the one indicator/accuracy ALINE can currently supply, so it's the only number
Jason wants used, ever, in this kind of asset. Do **not** use the runout-specific
0.002"/0.001"-above-3,600-RPM figures from the post's "How to check for runout"
section — those are accurate but explicitly excluded from use here per Jason's
instruction. Default expectation is no on-image text at all, matching both reference
posts.

## 4. Audience
Millwrights, maintenance supervisors, contract-firm project managers (per
company-brief.md — not reliability engineers). What should stand out to them: realism.
The reference posts work because they look like an actual plant environment, not a
stock photo or a graphic-design treatment — the coupling, gauges, and equipment need
to read as genuine industrial hardware a millwright would recognize, with the dial
indicator/magnetic base setup clearly legible as the focal point.
